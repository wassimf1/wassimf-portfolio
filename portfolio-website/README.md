# Wassim Farhat | Portfolio

Personal portfolio: electrical & automation engineering. Plain HTML/CSS/JS, no build step.

## Files
- `index.html`: the whole site
- `assets/wassim.jpg`: hero photo
- `reports/`: one-page project summaries (PDF, see `reports/README.md` for names)
- `images/`: page-1 preview of each PDF, shown next to its View/Download links. Generate them with `sh make-thumbnails.sh` (or export your own JPGs with the same names)
- `Wassim_Farhat_CV.pdf`: add your CV at the repo root

## Publish with GitHub Pages
1. Create a repo (e.g. `wassimf1.github.io` for a root URL, or any name).
2. Upload everything in this folder, keeping the structure.
3. Settings > Pages > Source: **Deploy from a branch** > `main` / `(root)` > Save.
4. Your site appears at `https://wassimf1.github.io/` (or `/repo-name/`) in about a minute.
